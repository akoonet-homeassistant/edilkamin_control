⚠️ Passage à la 2026.11.2 · Upgrading to 2026.11.2

Cette version change la répartition de la mémoire de l'ESP32 pour permettre la mise à jour à distance. Installez-la une dernière fois par USB en répondant non à « Effacer l'appareil » : le Wi-Fi est conservé. Au redémarrage, l'ESP32 ouvre le Wi-Fi Edilkamin_BT_AP : connectez-vous-y, ouvrez Setup et ressaisissez seulement le serveur MQTT (les anciens réglages MQTT ne peuvent pas être repris). Les réglages sont désormais gardés comme le Wi-Fi, et les versions suivantes s'installeront depuis Home Assistant (Paramètres → Mises à jour).

This release changes the ESP32 memory layout to allow remote updates. Install it one last time over USB, answering no to “Erase device”: Wi-Fi is kept. On restart, the ESP32 opens the Edilkamin_BT_AP Wi-Fi: join it, open Setup and enter only the MQTT broker again (old MQTT settings cannot be carried over). Settings are now kept like Wi-Fi, and later releases install from Home Assistant (Settings → Updates).

🇫🇷 Installation et mise à jour

  1. Ouvrez cette page avec Chrome ou Edge sur un ordinateur.
  2. Branchez l'ESP32 en USB. Pour une première installation, gardez le bouton BOOT appuyé en branchant le câble.
  3. Cliquez sur Installer / mettre à jour, puis choisissez le port de l'ESP32.
  4. Mise à jour : répondez non à « Effacer l'appareil » pour garder le Wi-Fi, le serveur MQTT et le planning de secours.
    Première installation : répondez oui, puis connectez-vous au Wi-Fi Edilkamin_BT_AP pour saisir le Wi-Fi et le serveur MQTT.
  5. Au premier démarrage, mettez le poêle en mode appairage Bluetooth. L'appareil « Edilkamin » apparaît ensuite dans Home Assistant (MQTT).

Le firmware publie la version installée dans Home Assistant (appareil Edilkamin, « Version du logiciel »).

🇬🇧 Installation and update

  1. Open this page with Chrome or Edge on a computer.
  2. Plug the ESP32 in over USB. For a first install, hold the BOOT button while plugging the cable.
  3. Click Install / update, then pick the ESP32 port.
  4. Update: answer no to “Erase device” to keep Wi-Fi, MQTT server and fallback schedule.
    First install: answer yes, then join the Edilkamin_BT_AP Wi-Fi to enter your Wi-Fi and MQTT server.
  5. On first start, put the stove in Bluetooth pairing mode. The “Edilkamin” device then shows up in Home Assistant (MQTT).

Nouveautés · What's new — 2026.11.3

  • Le Bluetooth du poêle est libéré plus vite : la température est lue en premier, les lectures sont rapprochées et l'ESP32 se déconnecte dès que toutes les valeurs sont relues (au lieu de rester 30 s). La télécommande et l'application Edilkamin trouvent le poêle libre plus souvent.
    The stove Bluetooth is released sooner: temperature is read first, reads are closer together and the ESP32 disconnects as soon as all values are read (instead of staying 30 s). The remote and the Edilkamin app find the stove free more often.
  • Nouveaux capteurs « Occupation du Bluetooth » (% sur 15 min) et « Durée de connexion Bluetooth », aussi affichés sur la page web.
    New “Bluetooth occupancy” (% over 15 min) and “Bluetooth connection duration” sensors, also shown on the web page.
  • S'installe à distance depuis Home Assistant (Paramètres → Mises à jour) si l'ESP32 est déjà en 2026.11.2.
    Installs remotely from Home Assistant (Settings → Updates) when the ESP32 already runs 2026.11.2.

2026.11.2

  • Page web d'état à l'adresse de l'ESP32, protégée par mot de passe (identifiant admin, mot de passe réglé dans Home Assistant).
    Status web page at the ESP32 address, password protected (user admin, password set in Home Assistant).
  • Adresse IP publiée en MQTT (entité « ESP32 adresse IP », lien « Visiter » sur l'appareil).
    IP address published over MQTT.
  • Mise à jour à distance depuis Home Assistant ou depuis la page web, avec contrôle MD5 et retour à la version précédente en cas d'échec.
    Remote update from Home Assistant or the web page, with MD5 check and rollback on failure.
  • Puissance manuelle (Man. P1 à P5) : le mode automatique du poêle est coupé avant l'envoi, la puissance est enfin appliquée.
    Manual power (Man. P1 to P5): the stove's automatic mode is turned off first, so the power is now applied.
  • Lecture de l'horloge du poêle (valeurs brutes, format en cours d'identification).
    Stove clock read (raw values, format being identified).

    Fallback schedule v2: up to 10 slots, days of the week and silent mode, sent by the Edilkamin Control integration. v1 (5 slots) still accepted.
